# GraftLink

> *"Breathing life into Minicraft, one Graft at a time."*

GraftLink is a lightweight, high-performance modloader for **Minicraft+ Revived** powered by SpongePowered Mixin, OW2 ASM, and Java LaunchWrapper.

---

## Features

* **Grafts System**: Modular, standalone mod JARs placed directly into the `/grafts` folder.
* **Mixin Integration**: Bytecode transformation and dependency injection via SpongePowered Mixin.
* **GraftLink API**: Built-in Registries (Items, Tiles, Recipes), EventBus (Ticks, Keypresses, WorldGen), and Mod Loggers.

---

## Getting Started

### Prerequisites
* Java JDK 17 or higher

### Installation & Run Instructions

1. Clone this repository:
   git clone https://github.com//GraftLink.git
   cd GraftLink

2. Open "GraftLink/libs/
   Download Minicraft-plus-2.2.4.jar from https://github.com/MinicraftPlus/minicraft-plus-revived/releases/tag/v2.2.4 to this folder.

4. cd GraftLink
   .\gradlew run
